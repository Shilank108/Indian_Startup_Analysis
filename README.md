# 🚀 Indian Startup Funding Analysis

An interactive data analysis dashboard built using **Python, Pandas, Matplotlib, and Streamlit** to explore the Indian startup funding ecosystem.

The project starts from a raw startup funding dataset, performs data cleaning and preprocessing in Jupyter Notebook, and finally presents insights through an interactive Streamlit dashboard.

---

## 📌 Project Workflow

Raw Dataset (.csv)
↓
Data Cleaning & Preprocessing (Jupyter Notebook)
↓
Cleaned Dataset (.csv)
↓
Interactive Streamlit Dashboard

---

## 🎯 Project Objective

The goal of this project is to analyze Indian startup funding trends and answer questions such as:

- How much funding has been raised over the years?
- Which sectors receive the most investments?
- Which investors are the most active?
- Which cities attract the highest funding?
- What funding rounds are most common?
- How has startup funding changed over time?

---

## 📊 Dashboard Features

### 1. Overall Analysis

Provides a high-level overview of the Indian startup ecosystem.

Includes:

- Total funding raised
- Maximum funding received
- Average funding amount
- Total startups funded
- Year-wise funding trends
- Startup funding trends over time
- Top sectors by startup count
- Top sectors by funding amount
- Top investors
- Top cities

---

### 2. Investor Analysis

Analyze any investor individually.

Includes:

- Most recent investments
- Top investments made
- Common investment sectors
- Common investment rounds
- Preferred investment cities
- Year-wise investment activity

---

### 3. Startup Analysis

Analyze individual startups.

Includes:

- Industry
- Sub-industry
- Location
- Funding history
- Investors involved
- Funding rounds
- Amount raised

## ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Shilank108/Indian_Startup_Analysis.git
```

Move into the project directory:

```bash
cd Indian_Startup_Analysis
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run indian_startup_project.py
```
